# interview-daily · 每日面试题

An auto-generating interview-prep site. Every day a GitHub Action asks an LLM to write one interview question (with a structured breakdown) for a rotating role, commits it as JSON, and publishes a static page via GitHub Pages.

**Live:** https://jason1105.github.io/interview-daily/

## How it works

1. `daily.yml` runs on a schedule (`cron: 0 0 * * *`, i.e. 00:00 UTC daily) — or on manual **workflow_dispatch**.
2. The role rotates by day of year (`ROLES[day_of_year % len(ROLES)]`), so consecutive days cover different positions.
3. `generate.py` calls an LLM (default **DeepSeek** `deepseek-v4-flash`, provider-configurable) and asks for one question plus a breakdown: 考察点 / 解题框架 / 示例 / 常见坑 / 追问.
4. Output is written to `questions/{date}.json`, mirrored to `questions/latest.json`, and appended to `questions/index.json`.
5. `index.html` renders today's card and the recent history. History entries are **clickable** — expand to see the full breakdown — and each can be marked **已复习** (stored per-browser in `localStorage`).

## Data shape

Each `questions/{date}.json`:

```json
{
  "question": "…",
  "type": "…",
  "difficulty": "…",
  "tags": ["…"],
  "breakdown": {
    "focus": "考察点",
    "framework": "解题框架",
    "example": "示例",
    "pitfalls": "常见坑",
    "followup": "追问"
  },
  "date": "YYYY-MM-DD",
  "role": "…",
  "practice_url": "…"
}
```

## Setup (fork it yourself)

1. Fork this repo and enable GitHub Pages (Settings → Pages → Source: GitHub Actions).
2. Add the LLM API key as a repository **secret**:

   | Secret | Value |
   |--------|-------|
   | `LLM_API_KEY` | Your DeepSeek key from [platform.deepseek.com](https://platform.deepseek.com) (`OPENROUTER_API_KEY` also accepted as a fallback) |

3. (Optional) Run the workflow once manually (Actions → Daily → Run workflow) to generate the first question.

## Configuration

- **Model** — set the `LLM_MODEL` repository variable to any DeepSeek model ID (default `deepseek-v4-flash`), or `LLM_BASE_URL` to point at another OpenAI-compatible provider (default `https://api.deepseek.com`). No code change needed.
- **Roles** — edit the `ROLES` list in `generate.py`.
- **Prompt** — edit `PROMPT_TEMPLATE` in `generate.py` to change what each question looks like.

## Robustness

`generate.py` guards against empty/invalid model responses: if the model returns something without a real question, it exits non-zero instead of overwriting `latest.json` / `index.json` with empty data (so a flaky run never destroys existing content).
